产品背景与定位

问题发现：青少年心理健康问题日益严峻，但专业心理咨询资源严重不足——学校心理老师配比不足、社会咨询费用高昂、学生主动求助意愿低。需要一种低门槛、无压力、随时可用的心理陪伴方式。

产品定位：不是专业心理咨询的替代品，而是「随时可倾诉、无评判、高安全」的第一道防线。就像一位耐心的朋友，在学生需要时提供倾听和陪伴，同时在真正危险的时刻引导他们寻求专业帮助。

🎯

低门槛触达

无需预约、无需实名、无需付费。打开即聊，降低心理求助的心理门槛。

🛡

安全第一

四级危机分级 + 安全护栏 + 热线引导。不诊断、不开药、不越界。

核心功能模块

1. AI 心理陪伴对话

对接大模型API，实现智能对话。核心在于体系化的 Prompt Engineering 设计，确保 AI 输出既温暖共情又安全可控。

/* System Prompt 核心结构 */ ## 核心原则 1. 无条件共情 — 先倾听、再复述、最后回应 2. 不越界 — 不诊断、不开药、不替代专业咨询 3. 温和表达 — 用"我感受到"，绝对禁止"你应该" 4. 隐私保护 — 不询问真实姓名、学校、住址 5. 正向引导 — 共情基础上提供具体可操作的小建议 ## 小学段特别要求（6-12岁） - 像温柔的大姐姐/大哥哥，用简单词汇 - 可以用童话比喻、小故事传递道理 - 每条回复50字以内，多用"勇敢""了不起" ## 初中段特别要求（12-15岁） - 平等对话，不居高临下 - 认可青春期情绪波动的正常性 - 遇到亲子冲突不站队，引导换位思考 ## 高中段特别要求（15-18岁） - 成熟但不冰冷，像理解你的学长学姐 - 认可高考压力、未来迷茫等现实困境 - 可讨论存在性议题，始终回归正向 ## 安全护栏 IF 自杀/自伤/被虐待 → 温和共情 + 引导求助 + 不讨论方法细节 IF 用户年龄≤14岁 → 额外强调"请告诉身边的大人"

2. 四级危机分级机制

这是本产品最核心的安全设计：根据用户表达内容自动判断风险等级，触发不同的产品响应策略。

🟢
无风险
日常陪伴模式
自由聊天 + 情绪感知
🟡
关注
加强共情
主动引导使用急救包功能
🟠
干预
自杀/自伤意念检测
引导联系心理老师/热线
🔴
危急
明确自杀计划检测
坚定引导 + 展示24h热线

3. 情绪追踪与可视化

每日心情打卡 → Canvas 绘制周/月情绪趋势曲线 → 帮助用户建立情绪觉察习惯。不同年龄段使用不同的打卡引导文案（如小学生"今天的心情像什么颜色？"，高中生"今天有什么想记录的瞬间？"）。

4. 紧急求助 & 呼吸引导

一键触发：安抚话术 + 4-2-6呼吸引导动画 + 24小时心理援助热线列表。三级年龄段不同的安抚文案和表达方式。

用户分层设计

三个年龄段的差异化产品策略——从AI语气、回复长度、干预话术到功能推荐完全不同。用户不是铁板一块。

🛡

安全合规思维

四级危机分级 + 安全护栏 + 不越界原则。医疗健康类产品的安全合规不是「附加功能」，而是产品成立的「前置条件」。

✍️

Prompt Engineering 体系

不是写一两条 prompt，而是设计了一套包含系统指令、年龄段适配、安全护栏、场景模板、Fallback 机制的完整 Prompt 体系。

🔄

边界场景处理

API 不可用时的降级策略、危机检测的误报与漏报权衡、隐私与安全的信息脱敏——产品经理必须考虑边界。
