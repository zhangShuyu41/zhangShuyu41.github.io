Product Story

产品故事：为什么做「心芽」

从一个真实的社会观察到一次完整的AI产品实践。

🔍

问题发现

青少年心理健康问题日益严峻——学校心理老师配比严重不足（很多学校1:1000+）、社会心理咨询费用高昂（200-500元/次）、学生主动求助意愿低（害怕被贴标签、担心隐私泄露）。现有的解决方案——学校心理咨询室（有门槛有压力）、社交媒体树洞（无专业引导、有风险）、心理热线（不够便捷、不够日常）——都无法满足「随时、无压力、专业陪伴」的需求。

🎯

产品定位

明确产品边界：不是专业心理咨询的替代品，而是「随时可倾诉、无评判、高安全」的第一道防线。就像一位耐心的朋友，在学生情绪刚出现波动时提供倾听和陪伴，在真正危险的时刻坚定地引导求助专业资源。核心设计原则：不诊断疾病、不开药、不替代专业咨询——但永远不让人感到孤单。

👶

用户分层设计

一个六年级的小学生和一个高三学生，他们的语言方式、情绪表达、认知水平完全不同。所以为小学（6-12岁）、初中（12-15岁）、高中（15-18岁）三个年龄段分别设计了完全不同的AI人格：小学生的回复像温柔的大姐姐——「我听到啦，你愿意多说一点吗？」；高中生则是成熟平等的对话——「我感受到你现在的困境，我们可以慢慢梳理。」

🛡

安全机制——产品成立的「前置条件」

心理陪伴类产品，安全不是「附加功能」，而是「产品是否成立的前置条件」。设计四级危机分级机制（无风险→关注→干预→危急），每级自动触发不同的Prompt策略和产品响应。建立了从关键词检测→情绪感知→危机分级→分级干预的完整安全链路。当检测到高风险内容时，AI不讨论方法细节，而是温和坚定地引导向专业求助资源。

🤖

AI实现与Prompt Engineering体系

借助Cursor完成全栈开发（React+TS+Express+Node.js），对接大模型API。构建了一套体系化的Prompt Engineering方案：分层System Prompt → 安全护栏 → 场景模板 → 危机应对策略 → API Fallback降级。在这个过程中深刻理解了「需求描述精度 → AI输出质量」的因果关系——产品经理对AI行为的定义，决定了用户体验的上下限。

Feature Highlights

功能亮点与设计思考

🧩

三层用户分层

小学/初中/高中三个版本拥有完全不同的AI人格、表达方式、回复深度和危机干预话术。不是简单的「改几个词」，而是重新设计整个交互体验——因为6岁和18岁的孩子不是同一种用户。

🛡

安全闭环设计

关键词检测 → 情绪感知 → 危机分级 → 分级干预 → 热线引导，形成完整的安全响应链。真正的产品安全不是「屏蔽敏感词」，而是「在正确的时机做正确的事」。

📊

情绪追踪与可视化

每日心情打卡 → Canvas实时绘制情绪趋势曲线 → 帮助用户建立情绪觉察习惯。不同年龄段使用不同的打卡引导文案，从「今天心情像什么颜色？」到「今天有什么想记录的瞬间？」。

🫁

4-2-6呼吸引导

针对焦虑场景的即时干预功能——吸气4秒→屏住2秒→呼气6秒，配合动画引导。三段年龄段不同的引导文案，小学生是「跟着小云朵一起呼吸」，高中生则给予「帮助你快速平静下来」的理性说明。

🆘

紧急求助入口

一键获取：安抚话术 + 24小时心理援助热线列表 + 呼吸引导。始终可见但不过度显眼——产品设计中的分寸感决定用户是否有安全感。

🔄

API不可用时的Fallback

当大模型API不可用时，自动降级为本地预设的高质量回复，确保服务不中断。产品经理必须考虑的边界场景——「正常情况」只是50%的体验，「异常情况」才是体验的上限。

Prompt Engineering

体系化 Prompt 设计

不是写一两条prompt——是设计一整套包含系统指令、年龄段适配、安全护栏、场景模板、降级机制的Prompt体系。

/* ═══════════════════════════════════════ 心芽 System Prompt 体系 ═══════════════════════════════════════ */ ## 核心人格定义 你是"心芽"，一个专为学生设计的心理陪伴AI助手。 你的核心定位：不做专业心理咨询师，做学生 "随时可倾诉、无评判、高安全"的心理陪伴者。 ## 五大核心原则 1. 无条件共情 // 先倾听→复述→再回应 2. 不越界 // 不诊断、不开药、不替代专业咨询 3. 温和表达 // "我感受到"而非"你应该" 4. 隐私保护 // 不询问真实姓名/学校/住址 5. 正向引导 // 共情基础上给具体可操作的小建议 ## 小学段适配（6-12岁） // 温柔大姐姐/大哥哥，童话比喻，每条回复≤50字 "我听到啦，你愿意和我多说一点吗？" "你知道吗，每个人都会有这样的时候。" "你可以试着画一幅画，把你现在的感觉画出来。" ## 初中段适配（12-15岁） // 平等对话，认可青春期情绪波动，不站队不居高临下 "我感受到你的心情了。谢谢你愿意分享。" "青春期有这些情绪波动非常正常。" "如果愿意，试试从对方的角度想想？" ## 高中段适配（15-18岁） // 成熟但不冰冷，像理解你的学长学姐 "我听到了，也感受到了。这些情绪是真实且值得被尊重的。" "高考压力、未来迷茫——这些是真实的困境。" "不需要急着'好起来'，先让情绪被看见就是力量。" ## 安全护栏（不可绕过） IF 自杀/自伤/被虐待 → 温和共情 + 坚定引导求助 + 绝不讨论方法细节 IF 用户年龄 ≤ 14岁 → 额外强调"请告诉身边你信任的大人" IF 危机关键词触发 → 自动附赠24h心理援助热线信息
Design Iteration

安全机制的迭代历程

安全机制不是一次设计出来的，而是不断追问「还有什么没考虑到」的结果。

V1.0 · 初版安全设计

2级
安全分级
  • 只有「正常」和「危险」两级
  • 敏感词匹配过于机械
  • 误报率高：很多正常倾诉被误判
  • 没有年龄差异化干预
  • 问题：不够精细，用户被误判后体验差
追问「还有什么没考虑到？」
↓
重新设计安全边界

V2.0 · 当前版本

4级
精细分级
  • 无风险→关注→干预→危急 四级
  • 关键词+上下文语义联合判断
  • 每级对应不同的Prompt策略
  • 三段年龄 × 四级危机 = 12套干预话术
  • 加入API Fallback：不可用时也能安全响应
